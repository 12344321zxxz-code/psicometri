# סימולטור פסיכומטרי

אתר סטטי (GitHub Pages) לתרגול סימולציות מלאות מקובץ PDF:

- מעלים את קובץ הבחינה. האתר מזהה לבד את מטלת הכתיבה, את הפרקים (לפי הכותרת "פרק N - חשיבה …" בראש כל עמוד), את מפתח התשובות ואת טבלאות חישוב הציון.
- הפרקים מוצגים לפי הסדר כצילום של העמודים המקוריים, עם עיגולי תשובה ליד כל שאלה וסרגל תשובות למטה.
- שעון לא מוצג. 5 דקות לפני הסוף קופצת הודעה קטנה. כשהזמן נגמר, הפרק ננעל והבא מתחיל.
- בסוף מקבלים ציון (גלם, סולם אחיד, אומדן כללי) ותחקור לכל פרק: נכון/לא נכון, זמן לכל שאלה ושינויי תשובה. אפשר לייצא ל-JSON או CSV.
- ההתקדמות נשמרת בדפדפן, כך שרענון של הדף לא מאפס את הבחינה. הזמן ממשיך לרוץ כמו בבחינה אמיתית.

הכול רץ בדפדפן. שום קובץ לא עולה לשרת.

קבצים: `index.html`, `app.js` (הלוגיקה), `tables.js` (טבלאות המעבר), `style.css`, `vendor/` (pdf.js).
